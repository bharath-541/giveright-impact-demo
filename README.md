# GiveRight

A frontend-only demo of an education NGO's donation and volunteer landing page. No real payments or backend data collection are connected.

## Demo features
- Donation amount and recurrence selection with input validation.
- Simulated payment and a printable sample receipt.
- Volunteer skill and availability selection with transparent demo programme matching.
- Responsive layouts and reduced-motion support.

## Run locally
Open `public/index.html` in a browser. No build step or dependencies are required.

All information entered in the demo remains in the current browser session and is not submitted to a server.
